.최소 필수 엔드포인트
--
이러한 엔드포인트는 모든 Console 에이전트 배포에 필수적입니다. AWS 또는 Azure에서 NetApp 리소스를 관리하려면 추가 엔드포인트가 필요합니다.

[cols="2a,1a"]
|===
| 엔드포인트 | 목적 <stdin> - include::endpoints-agent.adoc[tag=nss-endpoints]에서 해결되지 않은 지시문 <stdin> - include::endpoints-agent.adoc[tag=saas-endpoints]에서 해결되지 않은 지시문 <stdin> - include::endpoints-agent.adoc[tag=upgrade-endpoints]에서 해결되지 않은 지시문 
|===
--
.AWS 리소스용 추가 엔드포인트
--
Console 에이전트를 온프레미스에 설치하는 경우 AWS에 배포된 NetApp 시스템(예: Cloud Volumes ONTAP)을 관리하기 위해 다음과 같은 추가 AWS 엔드포인트에 대한 네트워크 액세스가 필요합니다.

[cols="2a,1a"]
|===
| 엔드포인트 | <stdin>의 미해결 지시문 - include::endpoints-agent.adoc[tag=aws-endpoints] 
|===
--
.Azure 리소스용 추가 엔드포인트
--
콘솔 에이전트를 온프레미스에 설치할 경우 Azure에 배포된 NetApp 시스템(예: Cloud Volumes ONTAP)을 관리하기 위해 다음과 같은 추가 Azure 엔드포인트에 대한 네트워크 액세스가 필요합니다.

[cols="2a,1a"]
|===
| 엔드포인트 | 목적 <stdin>에서 해결되지 않은 지시문 - include::endpoints-agent.adoc[tag=azure-public-endpoints] <stdin>에서 해결되지 않은 지시문 - include::endpoints-agent.adoc[tag=azure-china-endpoints] 
|===
