2+| *상용 지역 또는 주권 지역* 상용 지역 또는 주권 지역에 Console 에이전트를 설치하는 경우 설치 프로그램은 다음 엔드포인트에 대한 액세스가 필요합니다. 
|===
옵션 1에 나열된 엔드포인트는 보안성이 더 높으므로 권장됩니다. 방화벽에서 옵션 1에 나열된 엔드포인트는 허용하고 옵션 2에 나열된 엔드포인트는 차단하도록 설정하는 것이 좋습니다. 다음 사항에 유의하십시오. ** 옵션 1에 나열된 엔드포인트는 Console 에이전트 3.9.47 릴리스부터 지원됩니다. 이전 버전의 Console 에이전트와는 하위 호환성이 없습니다. ** Console 에이전트는 옵션 2에 나열된 엔드포인트에 먼저 연결합니다. 해당 엔드포인트에 액세스할 수 없는 경우 Console 에이전트는 자동으로 옵션 1에 나열된 엔드포인트에 연결합니다. ** NetApp Backup and Recovery 또는 NetApp Ransomware Resilience와 함께 Console 에이전트를 사용하는 경우 옵션 1의 엔드포인트는 지원되지 않습니다. 이 경우 옵션 1에 나열된 엔드포인트는 차단하고 옵션 2에 나열된 엔드포인트는 허용할 수 있습니다.

호스트는 설치 중에 운영 체제 패키지를 업데이트하려고 할 수 있습니다.  호스트는 이러한 OS 패키지에 대해 다양한 미러링 사이트에 접속할 수 있습니다.
