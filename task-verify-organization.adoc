= NetApp Console에서 조직을 확인하세요
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
조직 인증을 통해 Console 조직을 NetApp 비즈니스 계정 ID와 연결할 수 있습니다. 이를 통해 Digital Advisor 및 AIQ 권장 사항과 같은 기능을 사용할 수 있습니다.

.필수 역할
조직 관리자 또는 슈퍼 관리자.link:reference-iam-predefined-roles.html["액세스 역할에 대해 자세히 알아보세요."]

귀사가 NetApp에 둘 이상의 비즈니스 계정을 보유하고 있는 경우 조직을 인증하고 올바른 비즈니스 계정과 연결해야 합니다. 귀사가 NetApp에 비즈니스 계정이 하나만 있는 경우 조직은 자동으로 인증되어 해당 비즈니스 계정에 연결됩니다.

Console 조직이 비즈니스 계정과 연결되어 있으면 Digital Advisor에는 해당 계정과 연결된 리소스만 표시됩니다. 비즈니스 계정이 여러 개인 경우 Console 조직과 연결할 계정을 하나 선택해야 합니다. 연결을 변경해야 하는 경우 조직을 다시 확인하고 다른 비즈니스 계정을 선택할 수 있습니다.

.단계
. *관리 > ID 및 액세스*를 선택합니다.
. *조직*을 선택하세요.
. *조직* 페이지에서 페이지 제목 옆에 있는 *확인*을 선택합니다.
+
image:screenshot-iam-verify-org.png["페이지 제목 옆에 확인 버튼이 표시된 조직 페이지의 스크린샷입니다."]

. *비즈니스 계정 연결* 대화 상자에서 조직과 연결할 비즈니스 계정을 선택합니다.
