= 통합 스토리지 관리를 위한 NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Console은 모든 클라우드 및 온프레미스 시스템 전반에 걸쳐 데이터를 관리하고 보호하는 데 도움을 줍니다. 데이터를 안전하게 유지하고 원활하게 작동하도록 하는 도구가 포함되어 있습니다.

Console을 서비스형 소프트웨어(SaaS) 애플리케이션으로 사용하거나 클라우드 또는 온프레미스 환경(제한된 모드 또는 프라이빗 모드)에 설치할 수 있습니다. 각 모드는 서로 다른 기능 세트와 보안 요구 사항을 지원합니다.

Console은 사용자가 환경에 배포하는 Console 에이전트와 함께 작동하여 온프레미스 및 클라우드 환경 전반에서 리소스를 관리하고 프로세스를 오케스트레이션합니다.



== NetApp Console에 액세스하는 방법을 선택하세요

SaaS 애플리케이션에 가입(표준 모드)하거나, 클라우드에 설치(제한된 모드)하거나, 온프레미스에 설치(프라이빗 모드)하여 NetApp Console 사용을 시작하십시오. 제한된 모드 또는 프라이빗 모드에서는 일부 기능을 사용할 수 없습니다.

link:concept-modes.html["배포 모드에 대해 자세히 알아보세요"] .



== Console 에이전트를 사용하여 Console 기능 확장

콘솔 에이전트는 NetApp Console SaaS 애플리케이션 및 클라우드 기반 API에 대한 연결을 제공하여 고급 기능 및 데이터 서비스를 사용할 수 있도록 하는 경량 소프트웨어 구성 요소입니다.

제한된 모드 또는 프라이빗 모드에서 클라우드 또는 온프레미스 환경에 Console 에이전트를 설치하여 NetApp Console 애플리케이션에 액세스합니다. NetApp Console 및 해당 API에 직접 연결해야 하는 기능을 지원하려면 추가 에이전트를 배포해야 합니다.

link:concept-agents.html["콘솔 에이전트에 대해 자세히 알아보세요"] .



== NetApp Console에서 사용자 액세스 및 권한 관리

Console은 데이터 인프라 전반의 보안 및 제어를 강화하기 위해 ID 및 액세스 관리(IAM) 기능을 제공합니다. 조직의 역할과 책임에 따라 스토리지 및 데이터 서비스를 구성하여 무단 액세스 위험을 줄이는 동시에 운영 효율성을 유지합니다.

* 최상위 _organization_을 통해 전체 인프라에 걸쳐 스토리지 시스템 및 프로젝트에 대한 액세스 권한을 부여하고 취소할 수 있습니다
* _폴더_ 를 사용하면 업무 또는 규정 준수 요구 사항에 따라 스토리지 리소스와 프로젝트를 그룹화할 수 있습니다
* _프로젝트_를 사용하면 특정 스토리지 시스템, 볼륨 및 데이터 서비스에 액세스할 수 있는 팀을 제어할 수 있습니다
* _역할 기반 액세스 제어(RBAC)_ 를 사용하면 팀 구성원에게 다양한 수준의 스토리지 관리 권한을 부여할 수 있으므로 과도한 액세스 권한을 주지 않고도 작업을 위임할 수 있습니다


link:concept-identity-and-access-management.html["NetApp Console 에서 IAM에 대해 자세히 알아보세요"]



== NetApp Console의 보안 및 규정 준수

싱글 사인온(SSO)과 같은 보안 및 규정 준수 기능을 활성화하여 스토리지 및 데이터 서비스에 대한 액세스를 제어하세요. 조직 관리자 역할을 가진 사용자는 기본적으로 읽기 전용 모드를 설정할 수 있으며, 스토리지 시스템을 변경하거나 데이터 서비스를 사용하려면 관리자 권한을 요청해야 합니다. 또한 NetApp Console을 사용하여 스토리지 관리 및 사용자 활동을 모니터링할 수 있습니다. NetApp Console은 SOC 2 Type 2 인증을 획득했으며, NetApp은 고객에게 SOC 2 보고서를 제공합니다.

https://www.netapp.com/company/trust-center/compliance/soc-2/["NetApp의 SOC 2 보고서 보기"^]



== NetApp Console 기능 및 지원되는 스토리지

NetApp Console은 온프레미스 및 클라우드 환경 전반에 걸쳐 다양한 스토리지 유형, 기능 및 데이터 서비스를 지원합니다. Console을 사용하여 스토리지 시스템을 관리하고, 상태 및 성능을 모니터링하고, 데이터 서비스를 활성화하여 데이터를 보호하고 최적화할 수 있습니다.

=== NetApp Console의 스토리지 관리 및 상태 서비스

NetApp Console은 단일 인터페이스를 통해 NetApp 스토리지 인프라를 통합적으로 관리할 수 있도록 지원합니다.

Console에서 _Systems_는 검색되거나 배포된 스토리지를 나타냅니다. Console에서 스토리지 볼륨을 직접 관리하거나 시스템의 관리 인터페이스를 열어 더 많은 옵션을 사용할 수 있습니다.

image:screenshot-canvas.png["콘솔 화면에 여러 시스템이 표시된 스크린샷입니다. 하나를 선택하면 NetApp 데이터 서비스를 활성화하거나 스토리지 관리를 위해 *시스템 입력*을 선택할 수 있는 기능이 표시됩니다."]

스토리지 관리 외에도 인프라 서비스를 사용하여 모든 환경에 걸쳐 스토리지 인프라를 모니터링하고 관리하세요.

상태 및 성능 모니터링:: 스토리지 시스템의 상태 및 성능을 대시보드에서 확인하고, 문제가 발생하기 전에 해결할 수 있도록 알림을 받으세요.
Licenses and subscriptions:: 라이센스와 구독을 관리하고 모니터링하세요.
수명주기 계획:: 공간이 부족한 클러스터를 식별하고 필요에 따라 용량을 추가하거나 데이터를 이동하십시오.
NetApp 디지털 어드바이저(Active IQ):: 예측 분석과 사전 예방적 지원을 활용해 데이터 인프라를 최적화하세요.
소프트웨어 업데이트:: ONTAP 업그레이드의 평가, 계획 및 완료를 자동화합니다.
저장 알림:: ONTAP 환경에서 용량, 가용성, 성능, 보호 및 보안과 관련된 문제를 확인하세요.
시스템 페이지:: 모든 스토리지 시스템을 한 곳에서 확인하고 관리 인터페이스에 빠르게 액세스하세요. 시스템 페이지에서 드래그 앤 드롭으로 데이터 서비스를 바로 활성화할 수 있습니다.
지속 가능성 대시보드:: 저장 시스템의 지속 가능성을 분석합니다.




=== NetApp Console의 데이터 보안 및 보호 서비스

내장 데이터 서비스를 사용하여 중요 데이터를 보호하고 스토리지 효율성을 최적화하십시오.

NetApp Backup and Recovery:: 클라우드 및 온프레미스 데이터 백업 및 복원. 구독이 필요합니다.
NetApp Copy and Sync:: 온프레미스 데이터 저장소와 클라우드 데이터 저장소 간의 데이터를 동기화합니다.
NetApp Disaster Recovery:: 온프레미스 VMware 워크로드를 VMware Cloud on Amazon FSx for ONTAP 재해 복구 사이트로 사용하여 보호하십시오. 구독이 필요합니다.
NetApp Ransomware Resilience:: 랜섬웨어 공격으로 이어질 수 있는 이상 징후를 탐지합니다. 워크로드를 보호 및 복구합니다. 구독이 필요합니다.
NetApp Replication:: 백업 및 재해 복구를 지원하기 위해 저장 시스템 간에 데이터를 복제합니다.




=== NetApp Console의 비용 및 규정 준수 관리 서비스

모든 시스템에서 계약 상태를 추적하여 비용 관리, 규정 준수 및 구매 결정을 개선하십시오.

자동화 허브:: 스크립트 기반 솔루션을 사용하여 NetApp 제품 및 서비스의 설정과 연결을 자동화함으로써 더욱 원활하고 일관된 운영을 실현하십시오.
NetApp Cloud Tiering:: 온프레미스 ONTAP 스토리지를 클라우드로 확장하여 비용 최적화 및 데이터 라이프사이클 관리를 수행할 수 있습니다.
NetApp Data Classification:: 데이터 개인정보 보호 규정을 준수할 수 있도록 애플리케이션 데이터와 클라우드 환경을 안전하게 보호하세요. 구독 시 무료로 제공됩니다.
NetApp Volume Caching:: 쓰기 가능한 캐시 볼륨을 생성하여 데이터 액세스 속도를 높이거나 액세스가 많은 볼륨의 트래픽을 오프로드하여 성능 및 비용 효율성을 높일 수 있습니다.
NetApp 워크로드:: Amazon FSx for NetApp ONTAP을 사용하여 주요 워크로드를 설계, 설정 및 운영하여 특정 애플리케이션에 대한 성능과 비용을 최적화합니다.




=== NetApp Console 비용

NetApp은 Console에 대해 비용을 청구하지 않습니다. Console 에이전트를 배포하거나 클라우드에서 제한된 모드를 사용할 때 비용이 발생합니다. 일부 NetApp 데이터 서비스에도 관련 비용이 발생합니다.https://bluexp.netapp.com/pricing["NetApp 데이터 서비스 가격에 대해 알아보세요"^]
