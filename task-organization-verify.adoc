= NetApp Console 조직을 확인하십시오
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Digital Advisor를 사용하는 경우 회사에 NetApp의 여러 비즈니스 계정이 있는 경우 Console 조직을 확인해야 합니다. Digital Advisor는 Console 조직과 관련이 없는 여러 NetApp 계정을 표시할 수 있습니다. Console 조직과 연결된 리소스만 표시되도록 하려면 Console 조직과 연결할 비즈니스 ID를 확인할 수 있습니다.

콘솔은 사용자 계정당 하나의 NSS 계정을 연결하는 것도 지원합니다. link:task-manage-user-credentials.html["사용자 수준 자격 증명을 관리하는 방법을 알아보세요"] .



== 시작하기 전에

조직을 인증하려면 조직 관리자 역할이 있어야 하며, 사용자는 NetApp 지원 사이트(NSS) 계정과 연결되어 있어야 합니다. link:task-adding-nss-accounts["NSS 계정을 연결하는 방법을 알아보십시오"].


NOTE: 귀사에 비즈니스 계정이 하나만 있고 사용자가 NetApp 지원 사이트 계정과 연결되어 있는 경우, 조직 인증이 자동으로 수행됩니다.



== 조직 확인

.단계
. 사용자가 둘 이상의 조직에 액세스할 수 있는 경우 Organization 드롭다운 메뉴에서 확인할 조직을 선택합니다.
. *관리 > ID 및 액세스*에서
. *조직*을 선택하세요.
