= NetApp Console 배포 모드에 대해 알아보세요
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs:

[role="lead"]
NetApp Console은 SaaS 애플리케이션을 통해 사용하거나 클라우드 또는 온프레미스 환경 등 자체 환경에 직접 설치하여 사용할 수 있습니다.

NetApp에서는 이러한 사용 사례를 _배포 모드_라고 부릅니다. 각 모드는 비즈니스 및 보안 요구 사항에 따라 다양한 연결성, 기능 및 서비스를 제공합니다.

표준 모드(SaaS):: NetApp Console SaaS(서비스형 소프트웨어) 애플리케이션은 모든 NetApp 데이터 서비스, 자동 업데이트, ID 페더레이션 및 NetApp Support Site 로그인과 같은 유연한 인증 옵션에 대한 액세스를 제공합니다. 이 모드는 마켓플레이스 구독 및 BYOL 라이선스를 지원합니다. 이 모드는 대부분의 사용자 및 조직, 특히 NetApp Console에서 사용 가능한 최대한의 기능과 서비스를 원하는 사용자 및 조직에 이상적입니다.
제한된 모드(사용자 소유의 퍼블릭 클라우드에 설치):: 제한된 모드는 정부 기관이나 규제 대상 기업과 같이 강화된 보안과 제한된 연결이 필요한 조직을 위한 모드입니다. 사용자는 자체 퍼블릭 클라우드(정부, 국가 또는 상업용 지역)에 NetApp Console을 설치하고, NetApp Console API 엔드포인트(SaaS 애플리케이션에서 호스팅됨)에 대한 외부 연결이 제한됩니다. 제한된 모드는 Cloud Volumes ONTAP, Azure NetApp Files, NetApp Backup and Recovery(정부 및 상업용 지역의 경우), 데이터 분류를 포함한 주요 데이터 서비스와 자동 소프트웨어 업그레이드 및 ID 페더레이션에 대한 액세스를 제공합니다.
프라이빗 모드(사내 또는 클라우드에 설치):: 프라이빗 모드는 AWS Secret Cloud, AWS Top Secret Cloud, Azure IL6 또는 에어갭 환경과 같이 엄격한 보안 요구 사항이 있는 조직에 적합합니다. NetApp Console SaaS 애플리케이션이나 NetApp 클라우드 기반 API에 연결되지 않으므로 완벽한 제어 권한을 제공하고 외부 통신을 차단합니다. 지원되는 데이터 서비스에는 NetApp Backup and Recovery, NetApp Data Classification, NetApp Replication 및 Cloud Volumes ONTAP가 포함됩니다. 모든 스토리지 및 인증은 로컬에서 유지되므로 데이터가 사용자 환경 내에 안전하게 보관됩니다. 이 모드는 방위 산업체, 엄격한 데이터 상주 규칙이 있는 금융 기관 및 기밀 시스템을 사용하는 정부 기관에 적합합니다.



NOTE: NetApp Console은 제한된 모드 및 프라이빗 모드에서 데이터 흐름을 제한하지만 환경이 규정을 준수하는지 확인해야 합니다.

각 배포 모드는 아웃바운드 연결, 위치, 설치, 인증, 데이터 서비스 및 요금 청구 방법이 다릅니다.

=== NetApp Console의 표준 모드 작동 방식

콘솔은 표준 모드에서 다음과 같이 작동합니다.

아웃바운드 커뮤니케이션:: 에이전트에서 Console SaaS 애플리케이션, 클라우드 공급자의 공개적으로 사용 가능한 리소스 및 일상적인 운영에 필요한 기타 필수 구성 요소로의 연결이 필요합니다.
+
--
* link:task-install-agent-aws-console.html#networking-aws-agent["AWS에서 에이전트가 접촉하는 엔드포인트"]
* link:task-install-agent-azure-console.html#networking-azure-agent["Azure에서 에이전트가 연락하는 엔드포인트"]
* link:task-install-agent-google-console-gcloud.html#networking-gcp-agent["Google Cloud에서 에이전트가 연락하는 엔드포인트"]

Console 에이전트가 지원되는 위치:: 표준 모드에서는 Console 에이전트를 클라우드 또는 온프레미스에 설치할 수 있습니다.



NOTE: 클라우드에 에이전트를 설치하면 클라우드 사용료가 발생합니다.

콘솔 에이전트 업그레이드:: NetApp에서 에이전트 소프트웨어를 매달 자동으로 업그레이드합니다.
사용자 인터페이스 접근:: 퍼블릭 인터넷을 통해 사용할 수 있는 Console SaaS 애플리케이션에서 사용자 인터페이스에 액세스합니다.
API 엔드포인트:: API 호출은 다음 엔드포인트에 대해 수행됩니다: \ https://api.bluexp.netapp.com
입증:: NetApp Console은 auth0 또는 NetApp Support Site(NSS) 로그인을 통한 인증을 제공합니다. ID 페더레이션도 사용 가능합니다.

== NetApp Console 제한된 모드(사용자 고유의 퍼블릭 클라우드에 설치됨)

클라우드(정부, 국가 또는 상업 지역)에 콘솔 에이전트를 설치하면 NetApp 콘솔 API 엔드포인트(SaaS 애플리케이션에서 호스팅됨)에 대한 외부 연결이 제한됩니다.

사용자는 SaaS 애플리케이션이 아닌 Console 에이전트가 제공하는 로컬 UI에 액세스합니다.

사용하려는 데이터 서비스 및 기능에 따라 Console 조직 관리자는 하이브리드 클라우드 환경 내에서 데이터를 관리하기 위해 추가 Console 에이전트를 생성합니다.

link:task-install-restricted-mode.html["NetApp Console API에 대한 아웃바운드 연결에 대해 자세히 알아보십시오"].

다음 이미지는 제한 모드 배포의 예입니다.

image:diagram-restricted-mode.png["이 개념도는 SaaS 애플리케이션과 auth0 인증이 가능한 퍼블릭 인터넷, 웹 기반 콘솔에 대한 액세스를 제공하는 에이전트가 실행되는 클라우드의 가상 네트워크, 그리고 온프레미스 데이터 센터의 Cloud Volumes ONTAP 및 AFF 클러스터를 관리하는 환경을 보여줍니다."]

=== 제한된 모드에서 NetApp Console이 작동하는 방식

제한 모드에서 콘솔은 다음과 같이 작동합니다.

아웃바운드 커뮤니케이션:: 에이전트는 데이터 서비스 지원, 소프트웨어 업그레이드, 사용자 인증 및 메타데이터 전송을 위해 NetApp 클라우드 기반 API에 대한 아웃바운드 연결이 필요합니다.
+
--
NetApp은 에이전트와의 통신을 먼저 시작하지 않습니다. 에이전트가 모든 통신을 시작하며 필요에 따라 NetApp API 및 서비스에서 데이터를 가져오거나 내보낼 수 있습니다.

해당 지역 내에서 클라우드 공급자 리소스에 대한 연결도 필요합니다.

--
에이전트 지원 위치:: 제한된 모드에서는 정부 지역, 주권 지역 또는 상업 지역과 같은 클라우드에 에이전트를 설치합니다.
콘솔 에이전트 업그레이드:: NetApp Console은 매달 에이전트 소프트웨어를 자동으로 업그레이드합니다.
사용자 인터페이스 접근:: 사용자는 클라우드 지역에 배포된 에이전트 가상 머신을 통해 Console에 액세스합니다.
API 엔드포인트:: API 호출은 에이전트 가상 머신으로 이루어집니다.
입증:: 인증은 NetApp Console의 클라우드 서비스를 통해 auth0을 사용하여 제공됩니다. ID 페더레이션도 사용할 수 있습니다.




=== 제한 모드를 시작하는 방법

NetApp Console 계정을 생성할 때 제한된 모드를 활성화해야 합니다. 조직이 없는 경우, 설치된 Console 에이전트에 처음 로그인할 때 조직을 생성하고 제한된 모드를 활성화하라는 메시지가 표시됩니다.

조직을 생성한 후에는 제한된 모드 설정이 고정된다는 점에 유의하십시오. 나중에 제한된 모드를 활성화하거나 비활성화할 수 없습니다. link:task-quick-start-restricted-mode.html["제한 모드를 시작하는 방법을 알아보세요"].

=== NetApp Console이 비공개 모드에서 작동하는 방식

NetApp Console은 비공개 모드에서 다음과 같이 작동합니다.

아웃바운드 커뮤니케이션:: Console SaaS 애플리케이션(추가 API 엔드포인트가 있는 곳)에 대한 아웃바운드 연결은 필요하지 않습니다. 모든 패키지, 종속성 및 필수 구성 요소는 Console 에이전트와 함께 패키징되어 로컬 시스템에서 제공됩니다. 클라우드 공급자의 공개 리소스에 대한 연결은 Cloud Volumes ONTAP를 배포하는 경우에만 필요합니다.
Console 에이전트가 지원되는 위치:: 프라이빗 모드에서 Console 에이전트는 클라우드 또는 온프레미스 환경에서 지원됩니다.
콘솔 에이전트 업그레이드:: Console 에이전트 소프트웨어는 수동으로 업그레이드해야 합니다. NetApp은 정해지지 않은 간격으로 Console 에이전트 소프트웨어를 NetApp Support 사이트에 게시합니다.
사용자 인터페이스 접근:: 사용자는 클라우드 지역 또는 온프레미스에 배포된 Console 에이전트를 통해 Console에 액세스합니다.
API 엔드포인트:: API 호출은 Console 에이전트 가상 머신으로 이루어집니다.
입증:: 인증은 로컬 사용자 관리 및 액세스를 통해 제공됩니다. NetApp Console의 클라우드 서비스를 통해서는 인증이 제공되지 않습니다.
