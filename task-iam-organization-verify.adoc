= NetApp Console 조직을 확인하십시오
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
기본적으로 Digital Advisor는 콘솔 조직뿐만 아니라 회사와 연결된 모든 NetApp 계정을 표시합니다. Digital Advisor에 표시되는 내용을 특정 계정으로 제한하려면 콘솔 조직에서 사용할 비즈니스 계정을 확인하십시오.



== 시작하기 전에

조직을 인증하려면 조직 관리자 역할이 있어야 합니다. 또한 사용자는 NetApp 지원 사이트(NSS) 계정과 연결되어 있어야 합니다. link:task-adding-nss-accounts.html["NSS 계정을 연결하는 방법을 알아보십시오"].


NOTE: 회사에 비즈니스 계정이 하나만 있고 사용자가 NetApp Support Site 계정과 연결되어 있는 경우 Console에서 자동으로 조직을 확인합니다.



== 조직 확인

.단계
. 사용자가 둘 이상의 조직에 액세스할 수 있는 경우 Organization 드롭다운 메뉴에서 확인할 조직을 선택합니다.
. *관리 > ID 및 액세스*에서
. *조직*을 선택하세요.
. 페이지 제목 옆에서 *Verify*를 선택하세요.
+
image:screenshot-iam-verify-org.png["확인 버튼이 강조 표시된 조직 페이지의 스크린샷입니다."]

+

NOTE: 회사에 비즈니스 계정이 하나만 있는 경우 페이지 헤더 옆에 *Verified*라는 태그가 표시되며 별도의 조치가 필요하지 않습니다.

. *비즈니스 계정 연결* 대화 상자에서 드롭다운 메뉴를 사용하여 Console 조직과 연결할 비즈니스 계정을 선택합니다. 그런 다음 *연결*을 선택합니다.
