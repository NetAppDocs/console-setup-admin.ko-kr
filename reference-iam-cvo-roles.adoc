= NetApp Console의 Cloud Volumes ONTAP 액세스 역할
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
콘솔에서 사용자에게 Cloud Volumes ONTAP에 대한 액세스 권한을 부여하려면 다음 역할을 할당할 수 있습니다. Cloud Volumes ONTAP 역할을 사용하면 조직 내에서 사용자가 수행해야 하는 특정 작업에 맞는 역할을 유연하게 할당할 수 있습니다. 역할 할당 방식은 비즈니스 및 스토리지 관리 방식에 따라 달라집니다.

Cloud Volumes ONTAP는 다음과 같은 역할을 사용합니다.

* *Cloud Volumes ONTAP admin*: 모든 Cloud Volumes ONTAP 작업에 대한 전체 액세스 권한을 제공합니다.
* *Cloud Volumes ONTAP operator*: 볼륨, 애그리게이트, 스냅샷 및 복제본 추가, 일부 구성 수정, Cloud Volumes ONTAP 버전 업그레이드를 포함하여 Cloud Volumes ONTAP 시스템 검색 및 관리와 같은 중요한 스토리지 작업을 수행합니다.
* *Cloud Volumes ONTAP 뷰어*: Cloud Volumes ONTAP 정보에 대한 읽기 전용 액세스를 제공합니다. 이 역할은 능동적인 작업을 수행할 수 없습니다. 구성 정보가 포함된 일부 탭과 화면은 뷰어에게 표시되지 않을 수 있습니다.


모든 NetApp Console 액세스 역할에 대한 자세한 내용은 link:reference-iam-predefined-roles.html["액세스 역할"]을 참조하십시오.



[[how-role-changes-take-effect]]
== 역할 변경이 적용되는 방식

Cloud Volumes ONTAP는 각 역할 할당에 대한 로컬 캐시를 사용하여 역할 기반 액세스 제어(RBAC)를 적용합니다. 캐시는 매시간 자동으로 새로 고쳐집니다. 역할이 새로 할당되거나 변경된 경우 변경 사항이 적용되는 데 최대 1시간이 소요될 수 있습니다. 새로 고침이 완료되면 콘솔에서 해당 역할에 허용된 워크플로를 사용할 수 있습니다.


NOTE: 콘솔 에이전트를 처음 배포하거나 기존 콘솔 에이전트를 Console 4.9.0 이상 버전으로 업그레이드할 때 콘솔은 조직의 기존 사용자에게 Cloud Volumes ONTAP 역할을 할당하는 일회성 시딩 프로세스를 실행합니다. 이 프로세스는 완료하는 데 최대 30분이 소요될 수 있습니다.
