= NetApp Console의 Cloud Volumes ONTAP 액세스 역할
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
사용자에게 NetApp Console 내의 Cloud Volumes ONTAP에 대한 액세스 권한을 부여하려면 다음 역할을 할당할 수 있습니다.

* *Cloud Volumes ONTAP admin*: 모든 Cloud Volumes ONTAP 작업에 대한 전체 액세스 권한을 제공합니다.
* *Cloud Volumes ONTAP 운영자*: 볼륨, 애그리게이트, 스냅샷 및 복제본 추가, 일부 구성 수정, Cloud Volumes ONTAP 버전 업그레이드 등 Cloud Volumes ONTAP 시스템 검색 및 관리를 포함한 중요한 스토리지 작업을 수행합니다.
* *Cloud Volumes ONTAP 뷰어*: Cloud Volumes ONTAP 정보에 대한 읽기 전용 액세스를 제공합니다. 이 역할은 능동적인 작업을 수행할 수 없습니다. 구성 정보가 포함된 일부 탭과 화면은 뷰어에게 표시되지 않을 수 있습니다.


link:reference-iam-predefined-roles.html["액세스 역할에 대해 알아보세요"] .

Cloud Volumes ONTAP 시스템이 포함된 조직, 폴더 또는 프로젝트 수준에서 Cloud Volumes ONTAP 역할을 할당하십시오. 플랫폼 역할을 사용하면 사용자는 NetApp Console 리소스를 관리할 수 있고, Cloud Volumes ONTAP 역할을 사용하면 사용자는 Cloud Volumes ONTAP 시스템을 관리할 수 있습니다. 역할 할당 계획에 대한 지침은 link:task-cvo-rbac-setup.html#plan-cloud-volumes-ontap-role-assignments["Cloud Volumes ONTAP에 대한 역할 기반 액세스 설정"]을 참조하십시오.



[[role-migrations-for-existing-users]]
== 기존 사용자의 역할 마이그레이션

콘솔 에이전트를 버전 4.9.0 이상으로 업그레이드하면 콘솔은 기존 사용자의 플랫폼 역할에 따라 추가적인 Cloud Volumes ONTAP 역할을 할당합니다.


NOTE: 기존 콘솔 에이전트를 Console 4.9.0 이상으로 업그레이드하면 콘솔에서 조직의 기존 사용자에게 Cloud Volumes ONTAP 역할을 할당하는 일회성 시딩 프로세스가 실행됩니다. 이 프로세스는 완료하는 데 최대 30분이 소요될 수 있습니다. 시딩된 역할을 검토하고 조정하려면 link:task-cvo-rbac-setup.html#review-roles-after-upgrading-the-console-agent["콘솔 에이전트 업그레이드 후 역할 검토"]을 참조하십시오.

다음 매핑은 일회성 마이그레이션 프로세스에만 적용됩니다.

[cols="50,50"]
|===
| 기존 플랫폼 역할 | 시드 작업 중에 할당된 Cloud Volumes ONTAP 역할 


| 슈퍼 관리자 | Cloud Volumes ONTAP 관리자 


| 조직 관리자 | Cloud Volumes ONTAP 관리자 


| 연방 관리자 | Cloud Volumes ONTAP 관리자 


| 폴더 또는 프로젝트 관리자 | Cloud Volumes ONTAP 관리자 


| 슈퍼 뷰어 | Cloud Volumes ONTAP 뷰어 


| 조직 뷰어 | Cloud Volumes ONTAP 뷰어 


| 연방 뷰어 | Cloud Volumes ONTAP 뷰어 


| 폴더 또는 프로젝트 뷰어 | Cloud Volumes ONTAP 뷰어 


| 기타 플랫폼 역할 | Cloud Volumes ONTAP 뷰어 
|===
콘솔은 기존 플랫폼 역할과 동일한 계층 수준에서 Cloud Volumes ONTAP 역할을 할당합니다. 이러한 매핑은 새 역할 할당에는 적용되지 않습니다. 시드된 역할을 검토하고 조정하려면 link:task-cvo-rbac-setup.html#review-roles-after-upgrading-the-console-agent["콘솔 에이전트 업그레이드 후 역할 검토"]을 참조하십시오.


NOTE: 알려진 문제로 인해 *조직 뷰어* 및 *Cloud Volumes ONTAP 뷰어* 역할 조합이 조직 범위에서 작동하지 않습니다. 임시 해결 방법으로 *조직 관리자* 또는 *폴더 또는 프로젝트 관리자* 역할을 사용하십시오.
