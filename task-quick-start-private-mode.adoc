= 비공개 모드에서 NetApp Console 빠른 시작
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Console은 온프레미스 또는 보안 클라우드 환경에 설치할 수 있습니다. 프라이빗 모드는 일반적으로 인터넷 연결이 없는 온프레미스 환경과 https://aws.amazon.com/federal/secret-cloud/["AWS Secret Cloud"^], https://aws.amazon.com/federal/top-secret-cloud/["AWS Top Secret Cloud"^] 및 https://learn.microsoft.com/en-us/azure/compliance/offerings/offering-dod-il6["Azure IL6"^]를 포함하는 보안 클라우드 지역에서 사용됩니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["하나"] link:task-prepare-private-mode.html["배치 준비"]
[role="quick-margin-list"]
. CPU, RAM, 디스크 공간, 컨테이너 오케스트레이션 도구 등의 요구 사항을 충족하는 전용 Linux 호스트를 준비합니다.
. 대상 네트워크에 대한 액세스를 제공하는 네트워킹을 설정합니다.
. 클라우드 배포의 경우 소프트웨어를 설치한 후 Console 에이전트와 해당 권한을 연결할 수 있도록 클라우드 공급자에서 권한을 설정하십시오.


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["둘"] link:task-install-private-mode.html["콘솔 에이전트 배포"]
[role="quick-margin-list"]
. 사용자의 Linux 호스트에 Console 에이전트를 설치하십시오.
. 웹 브라우저를 열고 Linux 호스트의 IP 주소를 입력하여 NetApp Console을 설정합니다.
. 클라우드 배포의 경우, 이전에 설정한 권한을 NetApp Console에 제공하십시오.




[[supported-features-and-services-for-netapp-console-in-private-mode]]
== 비공개 모드에서 NetApp Console에 지원되는 기능 및 서비스

다음 표는 NetApp Console을 프라이빗 모드로 설치했을 때 사용할 수 있는 스토리지 관리 기능, 데이터 서비스 및 관리 기능을 나열합니다. NetApp Console을 클라우드에 설치하는 경우와 온프레미스에 설치하는 경우 기능이 다를 수 있습니다.



[[private-mode-installed-in-the-cloud]]
=== 클라우드에 설치된 프라이빗 모드

[cols="3*"]
|===
| 제품 영역 | NetApp 서비스 또는 기능 | Console 에이전트 필요 


.2+| *스토리지 시스템 관리* 이 표의 해당 부분은 NetApp Console에서 스토리지 시스템을 관리하는 데 지원되는 기능을 나열합니다. NetApp Backup and Recovery에서 지원하는 백업 대상은 표시하지 않습니다. | Cloud Volumes ONTAP | 네, 하지만 인터넷 접속이 불가능하기 때문에 자동 소프트웨어 업그레이드 및 AutoSupport 기능을 사용할 수 없습니다. 


 a| 
온프레미스 ONTAP 클러스터

* 클라우드(Console 에이전트가 설치된 위치)와 온프레미스 환경 간의 연결이 필요합니다.
+
온프레미스 ONTAP 클러스터를 검색하려면 Console 에이전트가 설치되어 있어야 합니다.


| Console 에이전트 없이도 직접 검색을 사용할 수 있지만, 관리 기능을 사용하려면 에이전트가 필요합니다. 


.3+| *데이터 서비스*  a| 
백업 및 복구

* 개인 모드에서 NetApp Backup and Recovery는 ONTAP 볼륨 데이터의 백업 및 복원만 지원합니다. https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-protect-journey.html#support-for-sites-with-no-internet-connectivity["ONTAP 데이터에 대해 지원되는 백업 대상 목록 보기"^] 애플리케이션 데이터 및 가상 머신 데이터의 백업 및 복원은 지원되지 않습니다.
* Google Cloud 또는 https://aws.amazon.com/federal/secret-cloud/["AWS Secret Cloud"^], https://aws.amazon.com/federal/top-secret-cloud/["AWS Top Secret Cloud"^] 또는 https://learn.microsoft.com/en-us/azure/compliance/offerings/offering-dod-il6["Azure IL6"^]에서 지원되지 않습니다

| 예 


 a| 
NetApp 분류

* 지원되는 데이터 소스는 로컬에서 검색할 수 있는 데이터 소스뿐입니다. https://docs.netapp.com/us-en/data-services-data-classification/task-deploy-compliance-dark-site.html#supported-data-sources["로컬에서 검색할 수 있는 소스 보기"^]
* 아웃바운드 인터넷 액세스가 필요한 기능은 지원되지 않습니다. https://docs.netapp.com/us-en/data-services-data-classification/task-deploy-compliance-dark-site.html#limitations["기능 제한 사항 보기"^]

| 예 


| NetApp Replication | 예* (ONTAP 온프레미스에서 ONTAP 온프레미스로 복제하는 경우에는 필요하지 않습니다) 


| *NetApp 지원 계약 기능* | None | -- 


.6+| *관리 기능* | 심사 | 아니요 


 a| 
Licenses and subscriptions 관리

* 프라이빗 모드에서는 BYOL만 지원됩니다.
+
Cloud Volumes ONTAP BYOL의 경우 노드 기반 라이센스만 지원됩니다. 용량 기반 라이센스는 지원되지 않습니다. 아웃바운드 인터넷 연결을 사용할 수 없으므로 NetApp Console에서 Cloud Volumes ONTAP 라이센스 파일을 수동으로 업로드해야 합니다.



https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/task-manage-node-licenses.html#add-unassigned-licenses["라이센스를 추가하는 방법을 알아보십시오"^]
| 아니요 


| ID 및 액세스 관리 | 예

| 알림 | 아니요
