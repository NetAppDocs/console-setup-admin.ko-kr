= NetApp Console 에 로그인하세요
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Console 에 가입한 후 웹 기반 콘솔에서 로그인하여 데이터 및 스토리지 인프라 관리를 시작할 수 있습니다.

가입 후에는 Console 조직 관리자가 리소스에 액세스하기 전에 사용자 계정을 조직에 추가해야 합니다. 로그인했지만 리소스가 표시되지 않으면 조직 관리자에게 문의하십시오. link:task-user-settings.html#contact-admin["조직 관리자에게 문의하십시오"].

.단계
. NetApp Console URL로 이동합니다. URL은 조직에서 사용 중인 Console 모드에 따라 다릅니다.
+
** *표준 모드*: 웹 브라우저를 열고 https://console.netapp.com["NetApp Console"^]으로 이동합니다.
** **제한된 모드 또는 프라이빗 모드**: 웹 브라우저를 열고 Console 에이전트가 설치된 IP 주소로 이동합니다.


. *로그인* 페이지에서 로그인에 사용된 이메일 주소를 입력하세요.
. 로그인에 사용된 인증 방법에 따라 자격 증명을 입력하라는 메시지가 표시됩니다.
+
** 기존 NetApp 지원 사이트(NSS) 자격 증명
** 이메일 주소와 비밀번호를 사용하는 NetApp Console 계정
** 관리자가 조직에 대해 ID 페더레이션을 설정한 경우 페더레이션 연결
