= 다른 Console 에이전트와 연결된 시스템 보기
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
조직에서 여러 Console 에이전트를 사용하는 경우 에이전트 간에 전환하여 특정 에이전트와 연결된 시스템을 확인할 수 있습니다.

조직 관리자 역할을 가진 사용자의 경우, 이 기능은 리소스 관리 전략을 구현할 때 유용합니다. 스토리지 시스템을 검색할 때 다른 에이전트로 전환하면 해당 시스템이 동일 환경에 있는 에이전트와 자동으로 연결됩니다.

스토리지 관리자의 경우 에이전트 간에 전환하여 각 에이전트와 연결된 시스템을 관리합니다.

예를 들어, 멀티클라우드 환경에서 조직은 AWS에 에이전트 하나와 Google Cloud에 에이전트 하나를 설치할 수 있습니다. 이러한 에이전트 간에 전환하여 각 클라우드 환경에서 Cloud Volumes ONTAP 시스템을 관리할 수 있습니다.


NOTE: 에이전트의 로컬 UI에서 NetApp Console을 볼 때는 이 옵션을 사용할 수 없습니다.

.단계
. *Storage* > *Management* > *Systems*를 선택합니다.
. 콘솔 에이전트 아이콘을 선택하세요(image:icon-agent.png["에이전트 아이콘"] )을 클릭하면 사용 가능한 에이전트 목록을 볼 수 있습니다.
+

.결과
콘솔이 새로 고쳐지고 선택한 에이전트와 관련된 시스템이 표시됩니다.
